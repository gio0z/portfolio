# AGENTS.md — portfolio

Agent-facing invariants and state facts. Authoritative narrative docs live in
`CONTEXT.md` (domain model, seams, vocabulary), `docs/runbooks/` (deploy and
rollback), `docs/security/` (threat model), `docs/superpowers/` (plans and
specs), `docs/analysis/` (whole-repo reviews).

## Stack and layout

- Single Go 1.23 binary (`main.go` → `internal/app`) serving `/api/*`, `/admin`
  and `/lab` auth+API, the MCP endpoint, and the static Astro output.
- `pkg/api` — public content API and static-serving seam.
- `internal/publishing` — draft/review/publish domain, SQLite registry,
  content-addressed artifact store.
- `internal/deployment` — two-phase publish (stage both destinations, then flip
  pointers) and rollback.
- `internal/preview` — sandboxed static-build runner (`docker` CLI, locked-down
  flags in `internal/preview/policy.go`).
- `internal/adminauth` — GitHub OAuth + PKCE, HMAC-signed sessions, CSRF,
  step-up approval verifier.
- `internal/mcppublisher` — agent-facing MCP tools with scoped bearer tokens.
- `frontend/` — Astro 7 static output with React 19 islands; `client:only`
  islands own `/admin` and `/lab`.
- `tools/contentexport` and `tools/statsgen` generate committed Go-sourced data.

## Commands

- Full gate (the only acceptance command): `bash scripts/run-publishing-e2e.sh`
  — race suite, `go vet`, vitest, Astro build, static-output contract,
  publishing E2E. CI (`.github/workflows/verify.yml`) runs exactly this script.
- Backend only: `go test -race ./...`, `go vet ./...`, `gofmt -l .`
- Frontend only: `cd frontend && npm test -- --run && npm run lint && npm run build`
- Local server: `go run . -port 8080` then open `http://localhost:8080`
- Regenerate content after editing `pkg/api/content.go`:
  `cd frontend && npm run prebuild`

## Invariants — do not break these

1. **Content single source of truth.** `pkg/api/content.go` is the only
   definition of profile/projects/skills. `frontend/src/content/portfolio.json`
   is generated by `tools/contentexport` and checked for staleness by the gate
   before the build. Never hand-edit the JSON.
2. **Fail-closed origins.** The Astro build exits non-zero when
   `PORTFOLIO_PUBLIC_ORIGIN` is unset. `LoadConfigFromEnv` refuses to start in
   production when any required origin, secret, or path is missing or weak
   (≥32-byte secrets), and rejects the dev approval verifier there.
3. **Atomic publication.** Project status must be written to `PUBLISHED` inside
   the same transaction as the submission state, or `ListPublishedProjects`
   returns rows that disagree with the artifacts on disk.
4. **Artifact bytes are verified.** Every read re-hashes the artifact and
   compares to `artifact_sha256`; every path from external input is either a
   64-char lowercase hex hash or a slug matching
   `^[a-z0-9]+(?:-[a-z0-9]+)*$`.
5. **Zero-JS static pages.** `/about`, `/work`, `/work/<id>`, `/services` emit
   only `ld+json` script tags. Hydration belongs to the coverflow, expertise
   tabs, and the contact form only.
6. **Islands keep absolute routes and no router basename.** `/admin` and `/lab`
   host client-routed islands that must stay `noindex` and must not appear in
   the sitemap or robots.txt.
7. **External links** sanitize to `http`/`https` at ingest (`NormalizeSourceURLs`)
   and render with `target="_blank" rel="noopener noreferrer"`.
8. **Security dialogs are conditionally mounted** (`{open && <ApprovalDialog/>}`)
   so step-up input never survives a reopen.
9. **Zero-warning gate.** `tsc` and `oxlint` must be clean; `.astro` stays in
   oxlint's `ignorePatterns`. Go code is always `gofmt`-formatted, pinned to Go
   1.23 syntax (no `new(expr)`), and `go.sum` stays tracked.
10. **Deploy is pull-based.** `hp-server-linux` runs a systemd timer that
    executes `deploy/deploy.sh` every minute; the script sets its own `HOME` and
    re-execs after updating the tree. Never assume a push deployed until the
    live origin answers with the new artifact.
